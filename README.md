# .NET Aspire Integration Tests

This project demonstrates a .NET application leveraging .NET Aspire for service orchestration and observability. It includes:
- A web API built with ASP.NET Core.
- Blazor web app.
- .NET Aspire for service discovery, resilience, and distributed system support.
- Integration tests using .NET Aspire's testing framework to validate the application's behavior in a distributed environment.

## Requirements

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or later
- Container runtime, e.g. Docker Desktop or Podman
